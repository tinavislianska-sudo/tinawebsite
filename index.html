CogniAgent — Social Content & Competitor Intelligence Pipeline

Social content and competitor tracking were both manual, ad hoc processes with no repeatable system behind them. I built a Claude Code pipeline that drafts on-brand posts end to end — idea to copy fact-checked against a technical skill built from CogniAgent's own documentation, to on-brand images, to a review-ready bundle — and a separate agent that watches competitor accounts across five platforms, alerts on anything new the moment it posts, writes up the gap where the brand could stand out, and feeds it straight back into the pipeline as a new post idea.

Inputs — what I combined

  • The cogniagent-technical skill, built from CogniAgent's own product documentation, as the fact-checker's grounding source
  • OpenAI's image API for on-brand visual generation

  • Kept publishing manual by design: the system produces upload-ready bundles, not autoposts, so a human makes the final call every time
  • Built a competitor-scout agent that reads live posts across five platforms, diffs them against what's already been seen, alerts on anything new, and writes up the gap where the brand could stand out

Reels Hook Generator

Content wasn't failing because of the idea — it was losing people in the first few seconds. I built a hook generator that analyzes attention-grabbing openings from selected creators, identifies the patterns behind their performance, and uses those insights to create hooks for any topic — designed to stop the scroll, increase engagement, and accelerate audience growth.

5× reach · 15× engagement · Skip rate reduced from 60% to 20%

Inputs — the structure I built
  • A browser-based login flow to access and analyze content from selected creators
  • A system for collecting relevant Reels and extracting their opening sequences
  • OpenAI Whisper to transcribe spoken hooks accurately
  • A structured database for storing transcripts, hooks, creators, and performance data
  • An analysis layer to identify recurring patterns, language, pacing, and psychological triggers
  • A generation workflow that combines these insights with the user's topic, audience, and content goal
Applied to — what I did with it
  • Built the complete workflow from creator selection and content collection to hook generation
  • Used Whisper to turn spoken Reel openings into searchable, structured transcripts
  • Analyzed successful hooks to uncover the patterns driving attention and engagement
  • Created topic-specific hooks inspired by proven structures without copying the original content
  • Built a simple interface for reviewing, comparing, and refining generated openings
  • Used the resulting hooks to achieve 5× reach, 15× engagement, and reduce the skip rate from 60% to 20%
